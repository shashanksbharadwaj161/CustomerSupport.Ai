# M0 bake-off harness

Measures STT, language ID, TTS, Claude replies and retrieval for en, ja, hi, bn, kn.
Every runner writes `eval/out/<name>.json` (gitignored); `python -m eval.make_report`
turns them into `eval/results.md` (committed). Nothing is estimated: missing numbers stay PENDING.

## 0. Where to run

```bash
python scripts/check_hardware.py
```

- `decision: local` (NVIDIA, >= 12 GB VRAM): run everything below on your PC.
- `decision: kaggle`: run the GPU steps (1-4) on a free Kaggle notebook, see `kaggle_m0.md`.
  Run step 5 (Claude, no GPU needed) on your PC so the API key never leaves it.

## 1. Test lines and recordings

- `lines/test_lines.jsonl`: 50 lines (10 per language) + 10 mixed/romanized. Regenerate from
  `lines/build_lines.py`. They are drafts: a native speaker reviews each language first
  (`lines/REVIEW.md`), then records.
- Record with `tools/recorder.html` (open via `python -m http.server` from the repo root, then
  http://localhost:8000/eval/tools/recorder.html). It saves `<line_id>.webm` files; put them in
  `eval/audio/` (gitignored). The runners decode any format with ffmpeg.
- Consent: only record people who agreed to it. Recordings stay local.

## 2. STT (needs recordings)

```bash
pip install -e ".[stt-whisper]"
python -m eval.runners.run_stt --engine faster-whisper --model large-v3
python -m eval.runners.run_stt --engine faster-whisper --model turbo
pip install -e ".[stt-indic]"        # gated model: accept terms on HF, export HF_TOKEN
python -m eval.runners.run_stt --engine indicconformer --decoding rnnt
python -m eval.runners.run_stt --engine indicconformer --decoding ctc
```

## 3. Language ID (needs recordings)

```bash
python -m eval.runners.run_lid --model large-v3
```
Copy the recommended threshold and prev_bias into `agent/engines.json` -> `lid`.

## 4. TTS (no recordings needed)

```bash
pip install -e ".[tts-kokoro]"   # also: apt install espeak-ng; python -m unidic download (Japanese)
pip install -e ".[tts-parler]"   # gated: accept terms on HF, export HF_TOKEN
pip install -e ".[tts-omnivoice]"  # DEMO ONLY (CC-BY-NC weights)
python -m eval.runners.run_tts --engines kokoro indic-parler   # first: refs for OmniVoice clones
python -m eval.runners.run_tts --engines omnivoice
python -m eval.runners.run_tts --roundtrip --engines kokoro indic-parler omnivoice   # optional intelligibility proxy
```
OmniVoice clone references are generated by Kokoro / Indic Parler, never recorded from a person.
If pip reports dependency conflicts between groups, use one virtualenv per group
(`python -m venv .venv-parler` etc.); the runners only import what they use.

## 5. Claude replies (costs money: the project's only spend)

```bash
pip install -e ".[llm]"
export ANTHROPIC_API_KEY=...        # M0 only; from M1 the key lives in the encrypted settings store
python -m eval.runners.run_llm                      # quick set, $0.50 cap
python -m eval.runners.run_llm --set full --max-usd 1   # only after the quick set looks right
python -m eval.runners.run_llm --model claude-sonnet-5-5 --langs kn bn   # fallback comparison
```

## 6. Retrieval

```bash
pip install -e ".[retrieval]"
python -m eval.runners.run_retrieval
```

## 7. Native-speaker ratings and the report

- `tools/rater.html` loads `eval/out/tts/manifest.json` and `eval/out/llm_*_manifest.json`
  (serve the repo root with `python -m http.server`). The rater picks their language, scores 1-5,
  and downloads a CSV. Save it as `eval/ratings/<rater>_<lang>.csv` (committed; no personal data
  beyond a rater nickname).
- `python -m eval.make_report` writes `eval/results.md`. Write engine decisions and fallbacks in
  `eval/decisions.md` (PLAN.md section 16); the report includes it.
